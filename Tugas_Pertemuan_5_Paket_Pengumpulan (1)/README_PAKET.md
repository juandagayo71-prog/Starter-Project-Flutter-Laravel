# PAKET TUGAS PERTEMUAN 5 — STARTER PROJECT FLUTTER & LARAVEL

Paket ini berisi starter code, dokumentasi arsitektur, laporan ringkas, dan template bukti pengujian.

## Yang harus diganti oleh kelompok
1. Nama kelompok dan nama/NIM seluruh anggota pada `FORM_PENGUMPULAN.md`.
2. URL repository GitHub Flutter dan Laravel setelah repository benar-benar dibuat.
3. Permalink `architecture.md` dari masing-masing repository.
4. Bukti screenshot dan log pengujian setelah aplikasi benar-benar dijalankan.

## Struktur
- `source_code/flutter_starter/`: starter Flutter dengan pola MVVM.
- `source_code/laravel_starter/`: berkas inti Laravel API dengan pola MVC.
- `source_code/docs/`: dokumentasi arsitektur.
- `dokumen_pengumpulan/`: laporan PDF dan template pengumpulan.

## Penting
Paket ini belum dapat diklaim sebagai sudah diuji di komputer kelompok. Flutter harus diuji dengan Flutter SDK. Folder Laravel berisi berkas inti dan perlu diintegrasikan ke instalasi Laravel lengkap melalui Composer. Jangan mengunggah `.env`, `vendor/`, atau folder build ke GitHub.
