# Tugas Proyek Pertemuan 5 — Starter Project Flutter & Laravel

Paket ini memuat:
1. `flutter_starter/` — starter Flutter dengan pola MVVM.
2. `laravel_starter/` — skeleton Laravel API dengan pola MVC, Request, Resource, routes, dan migration.
3. `docs/architecture_flutter.md` — dokumentasi arsitektur dan alur data Flutter.
4. `docs/architecture_laravel.md` — dokumentasi arsitektur dan alur API Laravel.
5. Form pengumpulan dan template log verifikasi tim.

## Catatan penting
- Ganti nama kelompok, anggota, dan tautan repo sesuai data tim.
- Buat dua repository GitHub yang terpisah, lalu unggah masing-masing folder starter ke repo terkait.
- Untuk Flutter, instal Flutter SDK dan jalankan perintah pada README Flutter.
- Skeleton Laravel ini berisi berkas aplikasi inti, bukan keseluruhan instalasi Laravel vendor/framework. Buat proyek Laravel bersih dengan Composer, lalu salin berkas `app`, `routes/api.php`, dan migration dari paket ini.
- Bukti screenshot dan log harus dibuat dari proses run yang nyata. Paket ini tidak memalsukan bukti eksekusi.
